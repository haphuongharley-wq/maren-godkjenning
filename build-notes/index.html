Build notes

How to put the sales page, the checkout page and the 8 sales emails into Kajabi, and every link that must be filled in before launch. The source files live in the private repo maren-project; public previews are in maren-kajabi-pages.

Build order

  1. Create the offers in Kajabi (section 1). The pages need the offer links.
  2. Create the pages in Kajabi for the sales page, the checkout page and the webinar replay page. Each page is one full-width Custom Code section; paste the whole HTML file. Note each page's URL.
  3. Fill in the links in the Fill these before publishing block at the top of each page's script (sections 2 to 4), then paste the page into Kajabi again.
  4. Set up the sales email opt-out: tag, confirmation page and automation (section 5).
  5. Fill in the email links in build-emails.py, rebuild, paste the 8 emails into Kajabi and schedule them (section 6).
  6. Test with ?dato= (section 7) and send each email to yourself.

5. Sales email opt-out

Every email ends with «Vil du ikke ha flere e-poster om Fra stress til ro? Klikk her, så stopper de. Du får fortsatt de vanlige e-postene mine.» That link is STOPP, still Missing.

To do

  1. Create the tag stopp-salg-fsr.
  2. Create a short confirmation page in Kajabi, for example «Takk, du får ikke flere e-poster om Fra stress til ro. De vanlige e-postene mine kommer som før.» This page's URL is the STOPP link.
  3. Tag whoever clicks. If Kajabi lets you attach an action to a link in an email, attach «add tag stopp-salg-fsr» to the «Klikk her» link in all 8 emails. If not, use a form on the confirmation page to add the tag.
  4. Keep tagged contacts out of the remaining emails:
    • Sent as a sequence: an automation «when tag stopp-salg-fsr is added, unsubscribe from the sales sequence».
    • Sent as scheduled broadcasts: the recipient segment excludes the tag stopp-salg-fsr.
  5. Do not use Kajabi's default unsubscribe link for this line; it removes the contact from the whole email list.

When pasting into Kajabi

  • Exclude: tag «aktiv coachingkunde», tag «avsluttet coachingkunde», attendees of the Advanced Training on 8 Nov, and contacts tagged kjøpt-fra-stress-til-ro or stopp-salg-fsr.
  • Check that the Kajabi site time zone is Europe/Oslo before scheduling.
  • Replace [Fornavn] with Kajabi's first-name merge tag (insert it from the merge tag button in the email editor).
  • The email images (logo, Maren's photo) load from the GitHub Pages site of maren-kajabi-pages. Keep that repo public for the whole campaign, or upload the images to Kajabi and change the src.
  • Paste the HTML through Kajabi's code/HTML block. Then send each email to yourself and click every link once.
  • Edit the wording only in copy/08-webinar-sales-sequence/sequence-no.md and rebuild. Never edit the HTML files directly.

7. Timing and testing

  • The deadlines live in DEADLINES on the sales page and the checkout page, in Oslo time: bonuses 2026-11-15 23:59:59, webinar price 2026-11-18 23:59:59. No change needed. Both pages were tested at 6 moments and give the same result in any viewer time zone.
  • Preview any moment by adding ?dato=2026-11-17T12:00 to the URL, for example the sales page after Wednesday.
  • If a page is open when a deadline passes: the checkout switches from the bonus countdown to the webinar price countdown, and after the price deadline both pages reload and show 14 990 kr.
  • After filling in the links, open all 3 pages and click every button. A «Forhåndsvisning: … ikke lagt inn ennå» notice means a link is still empty.
