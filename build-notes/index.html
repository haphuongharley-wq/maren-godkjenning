Build notes

How to put the sales page, the checkout page and the 8 sales emails into Kajabi, and every link that must be filled in before launch. The source files live in the private repo maren-project; public previews are in maren-kajabi-pages.

Build order

  1. Payment links are already in the pages (section 1). Plan the repricing for Thursday.
  2. Create the pages in Kajabi for the sales page, the checkout page and the webinar replay page. Each page is one full-width Custom Code section; paste the whole HTML file. Note each page's URL.
  3. Fill in the replay page links (section 4), then paste it into Kajabi again.
  4. Publish automation 1507478 (sales email opt-out form, section 5).
  5. Fill in the email links in build-emails.py, rebuild, paste the 8 emails into Kajabi and schedule them (section 6).
  6. Test with ?dato= (section 7) and send each email to yourself.

Add ordinary-price links there if those offers are made later.

Where the buttons go

  • Sales page, offer card: «Betal» goes to the Kajabi pay-in-full offer, «Del opp» to the Kajabi 3-payment offer, «Betal med Klarna» to Klarna, «Betal med Vipps» to Vipps in full, and the text link «Eller del opp med Vipps» to Vipps in 3 payments. No button goes through the checkout page. Every other button on the page scrolls to the offer card.
  • Checkout page: the main button and the Vipps button follow the chosen option (Delbetaling or Betal alt nå); the Vipps label shows the amount, for example «Betal med Vipps: 3 × 3 497 kr». The Klarna box goes to Klarna.
  • Klarna via Edpay is one payment; inside Klarna the buyer can pay within 30 days or split it, and Maren receives the full amount. Vipps in 3 payments is collected through Edpay, and Edpay says the seller manages instalment payments, so follow up any missed Vipps instalments.

Also in Kajabi

  • The bonuses (Minikurs i meditasjon and Morgenstrekk med Pia) are only for buyers before Sun 15 Nov, 23:59. The offers must deliver the bonuses to those buyers and stop doing so after Sunday 23:59.
  • Set the after-purchase thank-you page (maren-purchase-thank-you-page.html) as the thank-you page of the offers. Its CONFIG holds maren@detlillepusterommet.no. Leave FIRE_PURCHASE at false if Kajabi already sends the Meta Pixel Purchase event.
  • Each offer adds the tag kjøpt-fra-stress-til-ro on purchase, so buyers leave the sales emails (section 5). Check the same for purchases through Edpay (Vipps, Klarna).

Pages in Kajabi

All four pages are drafts in Kajabi with their content in. Each page is one code block (the replay page has two plus a video block), with Kajabi's default header and footer hidden. The images load from the public repo maren-kajabi-pages (kajabi/img/), so keep that repo public. After any change to a page, run page-source/build-kajabi-pages.py and paste or push the matching file from pages/kajabi/ again.

Open each page in the Kajabi builder preview (desktop and mobile) before publishing, to check that the theme does not change fonts or spacing.

Test before Sunday (about 15 minutes)

  1. Create a test event starting in 10 minutes with two event emails: «After the event» 5 minutes, and «After the event» 1 h 30 min (this also shows which time units the When field offers).
  2. Register two team test emails to it (Contacts, select, bulk action «Register to event»).
  3. After the event starts and before the 5-minute email, deregister one of them.
  4. If the deregistered contact does not get the email, the setup works. If they still get it, tell the build team: the fallback is an automation with weekly waits and exit conditions.

7. Timing and testing

  • The sales page and the checkout follow a weekly cycle in Oslo time (WEEK in each script): Sunday bonuses + webinar price until 23:59, Monday to Wednesday 23:59 webinar price, Thursday to Saturday ordinary price. Tested for two weeks in a row and across a daylight-saving change, in any viewer time zone.
  • Preview any moment by adding ?dato=2026-11-17T12:00 to the URL, for example the sales page on a Thursday.
  • If a page is open when a deadline passes: the checkout switches from the bonus countdown to the webinar price countdown, and after Wednesday 23:59 both pages reload and show 14 990 kr.
  • Open all 3 pages in Kajabi and click every button once. A «Forhåndsvisning: … ikke lagt inn ennå» notice means a link is still empty. Opening a Vipps link starts a real Vipps payment; just close it.
